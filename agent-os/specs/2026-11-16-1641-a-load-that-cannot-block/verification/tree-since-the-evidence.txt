"""The tree the four evidence runs read, and the tree now: every file that differs between the
two, and whether any of them is code that differs.

usage: tree_since.py <the files as they were then> <transcript>...   (from the repository root)

The four evidence runs of the remedy (mutation.txt, marker-count.txt, rollback-count.txt and
remedy-run.txt) ran before issue #25 had a number. The number was then written into three
docstrings, the README, the changelog and two standards. This run says what that did to the
tree those four read. It loads no plugin and runs no test.

**The two trees.** Each transcript prints, before its run, HEAD and the blob of every path git's
status named (tree.sh). The four must print one tree: that is the tree then. The tree now is
read the same way, here. A path differs when the two trees give it two blobs, or when one names
it and the other does not; a path neither names is as HEAD has it in both, HEAD being the same.

**Every path that differs is one of three kinds, and all are listed.**

- Code: under `src/` or `tests/`. Its text then and its text now are compared as syntax trees,
  below. The text then is a copy set aside before the number was written, and is used only if
  its blob is the one the transcripts print; a path the tree then did not name is read from HEAD.
- Not code: `README.md`, `CHANGELOG.md`, anything under `agent-os/standards/`, and this spec's
  own folder. Named, and not compared.
- Anything else. One such path, or one syntax tree that differs, and this run ends in STOP and
  exits 1: the four are then to be run again, not explained.

**How two texts are compared.** Each is parsed whole by `ast.parse`, by the Python that runs the
package. The parse itself keeps no comment, no blank line and no layout. From the parsed tree
one thing is dropped: in the module, and in each class and each function, the first statement
when it is a bare string, which is the string Python keeps as `__doc__` (the rule of
`ast.get_docstring`). A bare string anywhere else is kept. What is left is written out by
`ast.dump`, which leaves out line and column numbers, and the two texts are equal when the two
dumps are the same string: every statement, name and number, and every other string.

**The comparison is shown to tell, before its answer is read,** on copies of `host.py` as it was
then: one with a docstring changed and one with a comment changed, which must compare equal, and
one with a number changed, one with the words of a raised message changed and one with a
statement added, each of which must differ. If any of the five answers otherwise, the run stops.

**Whether a docstring is read by anything.** An equal result means the same behaviour only if
no code and no test reads a docstring or a source file's text. Every `.py` file git lists under
`src/` and `tests/` is parsed and searched for: the name or attribute `__doc__`; a call of
`getdoc`, `getsource`, `getsourcelines`, `getcomments`, `findsource` or `help`; an import of
`inspect`, `pydoc` or `doctest`, with what is then used of it; and, outside docstrings, any
string that could name a file that differs (`.py`, `.md`, `README`, `CHANGELOG`, `agent-os`).
Each hit is printed. The gate's own pytest line and the pytest options are printed beside them.

A string that is a whole statement and not the first of its body, as the note this code writes
under a constant is, is no value: Python keeps it nowhere, not as `__doc__`, and only a reader of
the source's text could see it, which the search above is for. Such a string is compared in the
syntax trees, where it is kept, and in this search it is printed and counted apart, as what it
is. The first try of this script, not kept, counted two of them as strings that name a file
that differs, each naming an earlier spec's `shape.md` in its words; the search was then made to
tell a string that is a value from one that is a statement, and prints both.
"""

import ast
import difflib
import re
import subprocess
import sys
from pathlib import Path

SPEC = "agent-os/specs/2026-11-16-1641-a-load-that-cannot-block/"
CODE = ("src/", "tests/")
NOT_CODE = (
    ("README.md", "the README"),
    ("CHANGELOG.md", "the changelog"),
    ("agent-os/standards/", "a standard, or the standards' index"),
    (SPEC, "this spec's folder"),
)
BLOB = re.compile(r"^    ([0-9a-f]{40}|\(deleted\))  (.+)$")
HEAD = re.compile(r"^  HEAD ([0-9a-f]{40})$")
READERS = {"getdoc", "getsource", "getsourcelines", "getcomments", "findsource", "help"}
MODULES = {"inspect", "pydoc", "doctest"}
NEEDLES = (".py", ".md", "README", "CHANGELOG", "agent-os")
HOLDERS = (ast.Module, ast.ClassDef, ast.FunctionDef, ast.AsyncFunctionDef)


def git(*arguments: str) -> str:
    return subprocess.run(["git", *arguments], capture_output=True, text=True, check=True).stdout  # noqa: S603, S607


def printed(transcript: Path) -> tuple[str, dict[str, str], bool]:
    """The tree a transcript prints before its run, and whether it says the tree did not move."""
    lines = transcript.read_text(encoding="utf-8").splitlines()
    start = next(n for n, line in enumerate(lines) if line.startswith("the tree before the run"))
    end = next(n for n in range(start, len(lines)) if lines[n].startswith("$ "))
    head = next(m.group(1) for line in lines[start:end] if (m := HEAD.match(line)))
    blobs = {m.group(2): m.group(1) for line in lines[start:end] if (m := BLOB.match(line))}
    still = any(line == "cmp: the tree after the run is the tree before it" for line in lines)
    return head, blobs, still


def tree_now() -> tuple[str, dict[str, str]]:
    """HEAD and the blob of every path git's status names, as tree.sh reads them."""
    status = git("status", "--porcelain=v1", "--untracked-files=all").splitlines()
    paths = sorted(line[3:] for line in status)
    blobs = {path: git("hash-object", path).strip() if Path(path).exists() else "(deleted)" for path in paths}
    return git("rev-parse", "HEAD").strip(), blobs


def parsed_without_docstrings(text: str) -> tuple[ast.Module, int]:
    """The text parsed, each `__doc__` string dropped; and how many were dropped."""
    tree = ast.parse(text)
    dropped = 0
    for node in ast.walk(tree):
        if not isinstance(node, HOLDERS) or not node.body:
            continue
        first = node.body[0]
        if isinstance(first, ast.Expr) and isinstance(first.value, ast.Constant) and isinstance(first.value.value, str):
            del node.body[0]
            dropped += 1
    return tree, dropped


def dump(text: str) -> tuple[str, int, int]:
    """What is compared: the dump, the number of nodes in it, the docstrings dropped."""
    tree, dropped = parsed_without_docstrings(text)
    return ast.dump(tree), sum(1 for _ in ast.walk(tree)), dropped


def same(one: str, other: str) -> bool:
    return dump(one)[0] == dump(other)[0]


def changed_once(text: str, old: str, new: str) -> str:
    if text.count(old) != 1:
        sys.exit(f"a control's text is found {text.count(old)} times, not once: {old!r}")
    return text.replace(old, new)


def controls(host_then: str) -> bool:
    """Five copies of host.py as it was then, each changed in one way; whether each answers as it must."""
    first_line = host_then.splitlines()[0]
    cases = (
        ("a docstring changed (the module's first line)", changed_once(host_then, first_line + "\n", first_line + " And a word more.\n"), True),
        ("a comment added on a line of its own", changed_once(host_then, "_FIRST_BUTTON = 1000\n", "# a comment that was not there\n_FIRST_BUTTON = 1000\n"), True),
        ("a number changed: _FIRST_BUTTON = 1000 made 1001", changed_once(host_then, "_FIRST_BUTTON = 1000\n", "_FIRST_BUTTON = 1001\n"), False),
        ("the words of a raised message changed: 'Vital ignored the state' made 'Vital ignored a state'", changed_once(host_then, 'f"Vital ignored the state: ', 'f"Vital ignored a state: '), False),
        ("a statement added: _FIRST_BUTTON given a second time", changed_once(host_then, "_FIRST_BUTTON = 1000\n", "_FIRST_BUTTON = 1000\n_FIRST_BUTTON = 1000\n"), False),
    )
    told = same(host_then, host_then)
    print(f"  {'ok ' if told else 'NOT'}  the copy unchanged: equal, as it must be")
    for what, text, equal in cases:
        answer = same(host_then, text)
        told = told and answer == equal
        print(f"  {'ok ' if answer == equal else 'NOT'}  {what}: {'equal' if answer else 'differs'}, and must {'be equal' if equal else 'differ'}")
    return told


def kind(path: str) -> str:
    if path.startswith(CODE):
        return "code"
    for prefix, what in NOT_CODE:
        if path == prefix or (prefix.endswith("/") and path.startswith(prefix)):
            return what
    return "ANYTHING ELSE"


def text_then(path: str, blobs_then: dict[str, str], aside: Path) -> str | None:
    """A code file's text as the tree then held it, or None when it cannot be had."""
    if path not in blobs_then:
        return git("show", f"HEAD:{path}")
    copy = aside / path
    if not copy.is_file() or git("hash-object", str(copy)).strip() != blobs_then[path]:
        return None
    return copy.read_text(encoding="utf-8")


def readers(differing: set[str]) -> int:
    """Print everything under src/ and tests/ that could read a docstring or a source file; count those that could matter."""
    files = sorted(set(git("ls-files", "-co", "--exclude-standard", "--", "src", "tests").splitlines()))
    python = [path for path in files if path.endswith(".py") and Path(path).is_file()]
    print(f"  .py files git lists under src/ and tests/, each parsed: {len(python)}")
    could_matter = 0
    hits = 0
    bare = 0
    bare_hits = 0
    for path in python:
        text = Path(path).read_text(encoding="utf-8")
        whole = ast.parse(text)
        imported = set()
        used: dict[str, set[str]] = {}
        for node in ast.walk(whole):
            found = None
            if isinstance(node, ast.Name) and node.id == "__doc__":
                matters = path in differing
                found = f"the name __doc__, this module's own docstring; the module {'DIFFERS' if matters else 'does not differ'}"
                could_matter += matters
            elif isinstance(node, ast.Attribute) and node.attr == "__doc__":
                found = "the attribute .__doc__ of something: COULD READ ANY DOCSTRING"
                could_matter += 1
            elif isinstance(node, ast.Call) and isinstance(node.func, ast.Name | ast.Attribute):
                name = node.func.id if isinstance(node.func, ast.Name) else node.func.attr
                if name in READERS:
                    found = f"a call of {name}: COULD READ A DOCSTRING OR A SOURCE"
                    could_matter += 1
            elif isinstance(node, ast.Import):
                imported |= {alias.name for alias in node.names if alias.name.split(".")[0] in MODULES}
            elif isinstance(node, ast.ImportFrom) and (node.module or "").split(".")[0] in MODULES:
                imported.add(node.module or "")
                used.setdefault(node.module or "", set()).update(alias.name for alias in node.names)
            if isinstance(node, ast.Attribute) and isinstance(node.value, ast.Name) and node.value.id in MODULES:
                used.setdefault(node.value.id, set()).add(node.attr)
            if found:
                hits += 1
                print(f"    {path}:{getattr(node, 'lineno', '?')}  {found}")
        for module in sorted(imported):
            names = sorted(used.get(module, set()))
            reads = sorted(set(names) & READERS)
            hits += 1
            could_matter += bool(reads) or module in {"pydoc", "doctest"}
            print(f"    {path}  imports {module}, and uses of it: {', '.join(names) or 'nothing by name'}{'  COULD READ: ' + ', '.join(reads) if reads else ''}")
        stripped, _ = parsed_without_docstrings(text)
        statements = {id(node.value) for node in ast.walk(stripped) if isinstance(node, ast.Expr)}
        for node in ast.walk(stripped):
            if not (isinstance(node, ast.Constant) and isinstance(node.value, str)):
                continue
            bare += id(node) in statements
            if not any(needle in node.value for needle in NEEDLES):
                continue
            hits += 1
            names_differing = any(Path(other).name in node.value or other in node.value for other in differing)
            shown = " ".join(node.value.split())
            shown = shown if len(shown) <= 100 else shown[:97] + "..."
            if id(node) in statements:
                bare_hits += 1
                print(f"    {path}:{node.lineno}  a string that is a whole statement, no value, holding one of the five: {shown!r}")
            else:
                could_matter += names_differing
                print(f"    {path}:{node.lineno}  a string that is a value, holding one of the five: {shown!r}{'  NAMES A FILE THAT DIFFERS' if names_differing else ''}")
    print(f"  the five sought in a string: {NEEDLES}")
    print(f"  strings that are whole statements and not `__doc__`, in all {len(python)} files: {bare}; of them holding one of the five, printed above: {bare_hits}")
    print(f"  hits printed above: {hits}; of them, those that could read a docstring or a file that differs: {could_matter}")
    return could_matter


def main(aside: Path, transcripts: list[Path]) -> int:
    print(f"parsed by Python {sys.version.split()[0]}, the repository's own .venv/bin/python: {Path(sys.executable) == Path.cwd() / '.venv/bin/python'}")

    print("\n== 1. the tree then: what the four transcripts print before their runs")
    trees = {transcript.name: printed(transcript) for transcript in transcripts}
    for name, (head, blobs, still) in trees.items():
        print(f"  {name}: HEAD {head}, {len(blobs)} paths, {'its tree did not move during its run' if still else 'ITS TREE MOVED OR IT DOES NOT SAY'}")
    head_then, blobs_then, _ = next(iter(trees.values()))
    one_tree = all((head, blobs) == (head_then, blobs_then) for head, blobs, _ in trees.values())
    all_still = all(still for _, _, still in trees.values())
    print(f"  the four print one tree: {one_tree}")

    print("\n== 2. the tree now")
    head_now, blobs_now = tree_now()
    print(f"  HEAD {head_now}, {len(blobs_now)} paths; HEAD is the HEAD then: {head_now == head_then}")
    if not (one_tree and all_still and head_now == head_then):
        print("\nSTOP: the four do not print one still tree on this HEAD; nothing below would mean anything")
        return 1

    print("\n== 3. the comparison shown to tell, on copies of src/patchbay_vital/host.py as it was then")
    host_then = text_then("src/patchbay_vital/host.py", blobs_then, aside)
    if host_then is None or not controls(host_then):
        print("\nSTOP: the comparison does not tell a changed statement from a changed docstring")
        return 1

    print("\n== 4. every path that differs between the two trees")
    paths = sorted(set(blobs_then) | set(blobs_now))
    differing = [path for path in paths if blobs_then.get(path) != blobs_now.get(path)]
    alike = [path for path in paths if blobs_then.get(path) == blobs_now.get(path)]
    print(f"  paths either tree names: {len(paths)}; the same blob in both: {len(alike)}; differing: {len(differing)}")
    print(f"  {'then':<42} {'now':<42} kind, path")
    for path in differing:
        then, now = blobs_then.get(path, "(as HEAD has it)"), blobs_now.get(path, "(as HEAD has it)")
        print(f"  {then:<42} {now:<42} {kind(path)}: {path}")
    kinds = {path: kind(path) for path in differing}
    code = [path for path in differing if kinds[path] == "code"]
    other = [path for path in differing if kinds[path] == "ANYTHING ELSE"]
    not_code = [path for path in differing if kinds[path] not in {"code", "ANYTHING ELSE"}]
    print(f"  code: {len(code)}; not code: {len(not_code)}; anything else: {len(other)}")
    print("  not code, by kind:")
    for _, what in NOT_CODE:
        named = [path for path in not_code if kinds[path] == what]
        print(f"    {what}: {len(named)}")
    print(f"  the same blob in both, under src/ and tests/: {sum(path.startswith(CODE) for path in alike)} files, not compared further: a blob is the content")

    print("\n== 5. each code file that differs: its syntax tree then and now, docstrings left out")
    equal = 0
    for path in code:
        then = text_then(path, blobs_then, aside)
        if then is None or not Path(path).is_file():
            print(f"  {path}: NO TEXT TO COMPARE (no copy with the blob the transcripts print, or the file is gone)")
            continue
        now = Path(path).read_text(encoding="utf-8")
        (dump_then, nodes_then, docs_then), (dump_now, nodes_now, docs_now) = dump(then), dump(now)
        equal += dump_then == dump_now
        print(f"\n  {path}: {'EQUAL' if dump_then == dump_now else 'DIFFERS'}")
        print(f"    the copy's blob is the one the transcripts print: {blobs_then.get(path, 'read from HEAD')}")
        print(f"    then: {nodes_then} nodes compared, {docs_then} docstrings dropped, {len(dump_then)} characters of dump")
        print(f"    now:  {nodes_now} nodes compared, {docs_now} docstrings dropped, {len(dump_now)} characters of dump")
        print("    the lines of text that differ (- then, + now):")
        for line in difflib.unified_diff(then.splitlines(), now.splitlines(), lineterm="", n=0):
            if not line.startswith(("---", "+++")):
                print(f"      {line}")
    print(f"\n  code files that differ: {len(code)}; syntax trees equal with docstrings left out: {equal} of {len(code)}")

    print("\n== 6. whether a docstring, or a file that differs, is read by the code or by a test")
    could_matter = readers(set(differing))
    for line in Path("scripts/gate.sh").read_text(encoding="utf-8").splitlines():
        if "pytest" in line and "uv run" in line and not line.lstrip().startswith("#"):
            print(f"  scripts/gate.sh runs: {line.strip()}")
    for line in Path("pyproject.toml").read_text(encoding="utf-8").splitlines():
        if line.startswith(("addopts", "testpaths")):
            print(f"  pyproject.toml, [tool.pytest.ini_options]: {line}")

    print("\n== 7. the answer")
    stop = bool(other) or equal != len(code) or could_matter > 0
    print(f"  paths that differ: {len(differing)} = code {len(code)} + not code {len(not_code)} + anything else {len(other)}")
    print(f"  code whose syntax tree differs: {len(code) - equal}; paths that are neither code nor one of the four kinds named: {len(other)}")
    print(f"  readers of a docstring or of a file that differs: {could_matter}")
    if stop:
        print("  STOP: the four evidence runs are to be run again on this tree, at the owner's word")
        return 1
    print("  the code the four evidence runs read is the code of this tree, docstrings apart")
    return 0


if __name__ == "__main__":
    sys.exit(main(Path(sys.argv[1]), [Path(argument) for argument in sys.argv[2:]]))

# Prints HEAD, git's status of the work tree and the blob of every path that status names, so two
# calls can be compared with cmp: the tree a run read, and the tree it left.

  if [ -e "$path" ]; then echo "    $(git hash-object "$path")  $path"; else echo "    (deleted)  $path"; fi
done
rm -f "${TMPDIR:-/tmp}/tree.$$"

# usage: transcript.sh <out file> <title> <script to embed>... -- <command...>   (from the repository root)
# Writes one transcript outside the tree: its date and branch, the machine and the tree before,

while [ "$1" != "--" ]; do scripts+=("$1"); shift; done

{
  echo "$title, run $(date '+%Y-%m-%d %H:%M %Z') on branch"
  echo "$(git branch --show-current), Vital at /Library/Audio/Plug-Ins/VST3/Vital.vst3"
